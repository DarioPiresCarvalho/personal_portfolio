My Journey

I’ve always been a positive and curious individual. I enjoy asking questions, learning about others and understanding why things work the way they do. Naturally, I also like helping others and solving problems. Every problem and collaboration is an opportunity to learn something new. As I encountered more problems I couldn’t solve myself, my interest in understanding the technologies behind the applications and devices we use every day continued to grow.

So, this year I decided to take my biggest step yet, to go from end-user to developer, where I could be the one making the design choices. I want to create systems that get the job done, rather than causing more frustration for the people using them.

Having previously tried to learn Python and SQL before, I wanted to approach things differently this time. My first priority was to build a solid foundation in HTML, CSS and JavaScript, the fundamentals of front-end development. I knew I needed these in order to bring my ideas to life, showcase what I’ve been learning, and eventually build projects to tackle problems I genuiely care about.

Of all my attempts at learning how to programme, this is the first time that things have really started to click. Thanks to The Odin Project, I’ve been able to put together a webpage from scratch, that works on mobile and desktop! It’s not perfect, but it’s something I can be proud of, a place that I can curate, improve and build upon as my learning journey continues.

I hope you like it!

Recipe Suggestion App

Python Practice

2025

One type of application I've never quite managed to make work for me is a recipe app. So, I decided to build my own command-line tool that takes the ingredients in your shopping basket and suggests recipes based on how closely they match what you already have.

Alongside work, I'd started learning Python as a way to get to grips with programming concepts. I wanted to put what I'd learned into practice by building something I could keep expanding and improving as my knowledge grew.

The tool compared the ingredients you have against those required by each recipe, calculates the proportion of ingredients available and ranks the results accordingly. It was a great opportunity to start writing my own functions and logic, while learning how to work with data stored in JSON files.

I quickly discovered how difficult it can be to maintain a recipe library containing thousands of lines of data if it isn't structured and organised properly.

Rock-Paper-Scissors

Having previously built a version of Rock Paper Scissors in Python, it was fitting the my first assignment was to revisit the project using JavaScript and explore how it could interact with a webpage. This was my first opportunity to put together what I'd learned about functions, variables and DOM manipulation to create something interactive.

The game logic itself was fairly straightforward, but I underestimated how challenging it would be to manage variables, function returns and the flow of information between different parts of the programme. One of my biggest learning points was understanding how scope affects variables and why returning values from functions is so important. I also found myself repeating sections of logic that could have been simplified with a better approach to how player and computer choices were assigned.

Can you reach 5 points before the computer?

Etch-A-Sketch

An interactive drawing grid where users can customise the grid size and choose their own drawing colour. The project dynamically generates the grid using JavaScript, allowing users to change its dimensions and start with a fresh canvas.

This was a great opportunity to develop my understanding of DOM manipulation, dynamically creating and removing elements, and using event listeners to respond to user input. I also explored how HTML inputs could be used to give users more control over the experience, including selecting their own colours.

Looking back, I'd like to expand on the core functionality with features such as an eraser, random colours and gradually darkening squares. For now, I'm happy to have built something interactive from scratch and gained a better understanding of how JavaScript can manipulate a webpage.

On mobile just tap each square to paint it!
